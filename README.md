# Windows WEB会議音声録音プログラム - プロンプト

このリポジトリには、Windows PCでWEB会議を行う際に全ての音声を録音するPythonプログラムを作成するための詳細なプロンプトが含まれています。

## 内容

- `PROMPT.md` - プログラム作成のための詳細な要件定義とガイドライン

## 概要

このプロンプトは、以下の機能を持つPythonプログラムの開発ガイドを提供します：

- システムオーディオ（スピーカー出力）の録音
- マイク入力の録音
- 両方の音声のミキシング
- WAV/MP3形式での保存
- Windows WASAPI対応
- GUIまたはCLIインターフェース

## 使用方法

`PROMPT.md`を参照して、AI開発アシスタントや開発者がプログラムを実装できます。

## ライセンス

このプロンプトは自由に使用・改変できます。
